# Cresvora — Official Corporate Website

> **Intelligence in Action. Innovation in Motion.**

Cresvora is a product-driven technology innovation company engineering intelligent hardware, AI-powered assistive solutions, IoT ecosystems, and next-generation wearables.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Custom Design System
- **Motion & Interactions:** Framer Motion
- **Icons:** Lucide React
- **Dynamic Theming:** Dark Mode & Light Mode with seamless transitions

---

## 🌟 Key Features

- **Cinematic Hero Experience:** Smoked glass hardware telemetry dashboard featuring embedded 4K video animation.
- **Product Initiatives:** Dedicated showcase and deep-dive architecture pages for:
  - **PathGuard:** Assistive vision & LiDAR spatial navigation for visually impaired individuals.
  - **PAWIT:** AI-powered canine vocalization analysis and pet wellness telemetry.
  - **Animal Emotion Detector:** 48 kHz bio-acoustic research hardware with real-time waveform decomposition.
  - **Human Smart Wearable:** Continuous vital indicators (PPG, SpO2, Temperature) and emergency SOS dispatch.
- **Technology Domains:** Silicon, firmware (ESP32 / Nordic nRF), edge AI, and full-stack companion software.
- **Dynamic Theming:** Instant, persistent toggling between Cinematic Navy Dark Mode and Architectural Cream Light Mode.
- **Complete Architecture:** All 10 homepage preview sections + dedicated standalone pages (`/about`, `/products`, `/research`, `/team`, `/careers`, `/contact`, `/legal/*`).

---

## 🚀 Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

---

## 📦 Production Build

```bash
npm run build
npm run start
```
